# 木序排柜 1.1.0-beta.9

“我的排柜”现在直接打开订单列表。点击“新增订单”导入文件，确认后自动进入当前订单审核。支持搜索、按状态/工厂/目的仓/创建日期筛选、排序和分页；可修改订单名称、客户和备注，通过“查看明细”审核件数等内容。删除先移入回收站，支持恢复订单及原方案。

启动新版会自动请求同资料目录的旧版退出，再打开新版；旧版正在排柜时先等待完成，不能安全退出时提示，不强制终止。重复启动同版或误点较旧版会复用已运行的新版。请先保存柜内调整并备份，未保存的浏览器调整不迁移。此功能不自动下载升级包。

所有安装包及说明书由 GitHub Actions 标准托管运行器构建。Windows 便携包自带 Python，无需单独安装运行环境；完整解压后双击“启动排柜工具.bat”。Mac 请按芯片类型选包。真实业务资料保存在本机用户目录，不包含在下载包中。

下载 ZIP，请勿下载 Source code 当作程序。说明书提供 PDF 和离线 HTML。继承此前上传失败预览清理、订单件数/CBM 分组识别和导入后自动选中当前订单的修复。
