# 木序排柜 1.1.0-beta.13

订单审核先显示问题总览，只列出实际存在的问题类型。每类写明需要确认什么、剩余多少款或行；点击分类后专注处理该类问题，完成后返回总览继续下一类，全部就绪才能进入排柜。

补产品、确认工厂、补体积与毛重按产品去重。同款多个仓显示一张任务卡，保存后关联未绑定的同款需求；各仓数量和交期仍独立保存。无码产品只合并原表同一行拆出的仓，避免误合并不同新品。数量、交期及其他异常按订单行核对，不会遗漏其他问题类型。

保留“全部明细”入口供复查与批量操作，提高问题说明和表格文字的可读性。更新通过版本号入口完成；全部安装包与使用指南在 GitHub 云端构建、验收和发布。
