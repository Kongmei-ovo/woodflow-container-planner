# 木序排柜 1.1.0-beta.12

审核订单遇到没有产品资料的新品，直接点这一行的“快速补新品”。原编码和名称自动带入，核实工厂、完整一件产品的总体积和毛重，继续核对数量与交期，点“保存新品及审核结果”即可，无需来回切换资料设置。

新产品会保存到资料库供以后复用；同款的未绑定仓可一次关联，件数和交期保持各仓独立。没有正式编码时只关联原表同一行拆出的仓，不把同名新品合并。重复编码、OEM或条码会提示使用已有产品。取消或保存失败不会留下半建产品。

已绑定但资料缺失的行可“就地补资料”；保存前需确认会更新资料库，其他订单会重新检查，已保存方案不变。体积或毛重不清楚时，请保留待审核。

beta.11 用户可点击版本号检查并下载本次更新，保存工作后重启即可。更早版本需手动下载一次新包。Windows 自带运行环境，Mac 按芯片选择下载包。三个平台安装包及七页 PDF/HTML 指南均由 GitHub Actions 云端构建并验收；不含客户资料。
