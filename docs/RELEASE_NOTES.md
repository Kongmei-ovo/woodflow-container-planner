# 木序排柜 1.1.0-beta.10

点击顶部或左下角版本号，可检查 GitHub 新版本、查看更新内容、下载并准备更新，再点击“已保存，重启更新”。正常启动会后台检查并提示，不会强制升级。

更新包自动匹配 Windows / Mac 芯片，显示下载进度，校验 SHA256 并在独立空目录试启动。网络、校验或试启动失败时保留当前版本。重启前自动备份本机资料；未保存的排柜调整须先另存版本，正在排柜须先完成计算。更新成功后，从支持更新功能的旧启动入口也会转到已安装的新版。

首次从 beta.9 或更早版本升级到本版，需手动下载、完整解压并启动一次本版，以后可通过版本号更新。请继续使用本版的启动入口，不要再使用更早版本的旧文件夹。

保留订单列表、搜索筛选、编辑和回收站恢复，以及此前导入识别和当前订单自动选中修复。程序和真实业务资料仍在本机，检查更新不会上传订单、产品资料或数据库。

全部安装包与六页 PDF/HTML 说明书通过 GitHub Actions 云端构建。Windows 包自带运行环境，完整解压后双击“启动排柜工具.bat”；Mac 按芯片选择 ZIP。请下载 ZIP，Source code 为源码。
